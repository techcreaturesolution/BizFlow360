# Project Rules & Guidelines

## ⚠️ STRICT RULE: `backend/` Folder is STRICTLY OFF-LIMITS

1. **NO MODIFICATIONS**:
   - Do NOT edit, update, rename, or delete any files or directories inside the `backend/` directory.
   - Do NOT modify any existing backend logic, APIs, configurations, or schemas.

2. **NO ADDITIONS**:
   - Do NOT create, add, or generate any new files, folders, tests, or scripts inside `backend/`.

3. **STRICTLY UNTOUCHABLE**:
   - The entire `backend/` directory must remain completely untouched.
   - All feature work, updates, UI changes, and bug fixes must be restricted to `frontend/` (or other non-backend project directories).
   - If information about backend endpoints or types is required, read-only inspection is permitted, but NO changes can ever be made.
